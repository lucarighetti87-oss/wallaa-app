# Wallaa 4.0.15 — Customer ID

- App Store version: 1.0
- iOS build: 16
- Automatic customer ID at registration: `WSB-XXXXXX`
- Login accepts either account email or Wallaa Customer ID plus password
- Customer ID is visible in Settings > Account and is read-only
- Existing accounts receive an ID automatically after backend migration
- Requires Wallaa Backend v4.0.15
