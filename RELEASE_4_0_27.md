# Wallaa 4.0.27 — Approved visual lock

This release applies the approved premium visual language directly to the production app code.

- Official iOS Wallaa shield icon is now the in-app brand mark.
- Home rebuilt with deeper cinematic glass, stronger neon hierarchy, larger SOS radar and tighter proportions.
- Pairing flow keeps every instruction readable and retains a real Back control.
- Bell opens the dedicated Notifications center.
- Notifications and Activity use proportional typography; “Cancella tutto” is compact and single-line.
- Map uses a dark cinematic grade over real OpenStreetMap tiles.
- Guardian Mode uses the same premium night-map treatment and brighter live route.
- Settings/Profile legacy cards are forced into the same premium dark system.
- Existing approved design files remain under `public/design-approved/` and are not regenerated.

Version 4.0.27, build 30.
