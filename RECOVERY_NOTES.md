# Wallaa source recovery

This project was reconstructed on 2026-09-14 from the last complete v4.0.49 source, the compiled v4.0.57/v4.0.64 app bundles, and the retained v4.0.59-v4.0.65 patch scripts.

The missing v4.0.50-v4.0.57 source layer was reconstructed from the behavior and literal code present in the compiled v4.0.57 bundle: Sentinel service/screen, nearby Sentinel map, push Sentinel offers, app navigation, and Notification Center API helpers. Subsequent retained patches are applied unchanged and remain the audit trail.
