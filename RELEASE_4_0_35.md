# Wallaa 4.0.35 — Home visual rebuild from approved design reference

## Scope
This release changes the Home presentation and motion layer while preserving the existing Wallaa Safety application logic, backend calls, BLE behavior, SOS flow, Guardian Mode, account/session logic and navigation results.

## Visual changes
- Dark futuristic background aligned to the approved design direction.
- Compact 44 px neon header controls, centered Wallaa wordmark, notification dot.
- Hero rebuilt with digital globe, grid depth, cyan network light and the existing Wallaa copy.
- Status and Wallaa Button cards rebuilt with glass/neon treatment and live green status glow.
- SOS visual rebuilt with glossy red core, radar rings, crosshair, pulse and press feedback.
- Quick actions rebuilt as premium glass panels with cyan icons and press feedback.
- Bottom navigation rebuilt with cyan active glow and restrained inactive states.
- Progressive card entrance, ambient sweep, globe motion, status pulse, device float and SOS radar animation.
- Reduced-motion support retained.

## Functional guarantee
The release does not replace the existing React/Capacitor application with Flutter. The provided Flutter sample was used only as a visual/motion specification. Existing handlers, navigation destinations and business-state values remain connected to the original Wallaa code.
