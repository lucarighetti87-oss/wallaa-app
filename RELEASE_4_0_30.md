# Wallaa 4.0.30 — Build 33

This release is a static visual rewrite, not only an animation pass.

- Reworked the existing Wallaa screens in-place.
- No reference images are embedded or used as UI assets.
- Home gains the cinematic hero geometry, globe/radar treatment, deeper glass panels, stronger cyan lighting and a larger SOS centerpiece.
- Guardian Mode gains a stronger live-map HUD, larger map stage, moving-route lighting and layered live status treatment.
- SOS Active and Resolved receive stronger emergency/safe-state hierarchy and cinematic lighting.
- Activity, Notifications, Map and Settings are forced into the same dark futuristic visual system.
- Existing flows, text, BLE logic, SOS logic, Guardian Mode and backend integration are preserved.
