# Wallaa 4.0.41 — Device UI premium restore

Versione: 4.0.41
Build iOS: 44

Questa release parte da 4.0.40 e mantiene integralmente i fix SOS / Guardian / live location.

## Correzioni grafiche schermata "Il mio Wallaa"
- Ripristinati bordi ciano luminosi, glow diffuso e profondità glass/scifi.
- Card principale Wallaa Button rifatta a due colonne: immagine dedicata a sinistra, testo leggibile a destra senza sovrapposizioni.
- Aggiunto micro-testo "PIÙ SICURI OGNI GIORNO" con barretta ciano.
- Aggiunto divisore "SEMPRE AL TUO FIANCO" nella card dispositivo.
- Aggiunto radar SOS in filigrana nella sezione "COMANDO SOS".
- Ripristinate icone grafiche click singolo/doppio/triplo (e indicatore coerente per gli altri trigger realmente supportati).
- Ripristinati chevron a destra delle righe gesto.
- Aggiunto footer "PROTEZIONE IN UN GESTO" con linee decorative.
- Metriche Batteria / Segnale / RSSI rese più luminose e coerenti con il mockup.
- Onde radar del dispositivo rese più visibili: azzurre se pronto/connesso, rosse se disconnesso, ambra se segnale debole.
- Schermata pairing conserva la stessa semantica visiva delle onde di stato.
- Logo Wallaa ufficiale mantenuto nelle intestazioni.

## Funzioni preservate
Non sono stati sostituiti gli handler reali di BLE, pairing, trigger SOS, Guardian Mode, live location, backend o Safety Network.
