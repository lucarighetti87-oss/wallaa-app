# Wallaa v4.0.12 — Basic / Pro architecture & final UX pass

- Real map background in Location with live GPS marker and radar overlay.
- Activity history automatically retained for 30 days, with “Clear all”.
- Profile data read-only by default; explicit “Edit my data” unlocks editing.
- Wallaa Basic / Wallaa Pro entitlement architecture added server-side.
- Wallaa Basic: max 2 personal SOS contacts, initial SOS position only.
- Wallaa Pro: max 5 personal SOS contacts, Wallaa Operating Center forwarding, movement live tracking.
- Future SMS entitlement reserved but intentionally hidden until implemented, to avoid incomplete App Store functionality.
- Operating Center is no longer included in Basic.
- Server alert/location retention default reduced to 30 days.
- Version 4.0.12, iOS build 13.
