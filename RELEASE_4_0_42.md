# Wallaa 4.0.42 — UI fixes, trigger LEDs, activity clear flow

Versione: 4.0.42
Build: 45

Questa release applica le ultime correzioni richieste sul flusso dispositivo/attività:

- onde concentriche di propagazione molto più visibili attorno al Wallaa Button;
- colore onde coerente con lo stato: azzurro se connesso/abbinato, rosso se non connesso, ambra se segnale debole;
- fix layout del microtesto “SEMPRE AL TUO FIANCO”, che ora resta dentro la card senza uscire dallo schermo;
- menu “Gesto del pulsante” aggiornato: rimossi i simboli > a destra;
- aggiunti LED di stato sulle gesture: verde animato per la selezione attiva, rosso animato per le altre opzioni;
- indicatori grafici delle gesture coerenti con lo stato attivo/inattivo;
- azione “Cancella tutto” nell’area Attività/Notifiche resa stabile, senza aperture di schermate anomale dopo la conferma;
- mantenute tutte le logiche esistenti di pairing, BLE, SOS, Guardian Mode, live location e notifiche.
